# include/

This directory is part of the submitted path set. It exists so the submission
archive can always be created, and so you have a place for your own headers.

The starter keeps its headers beside its sources in `src/`. You may leave that
arrangement alone, or move headers here. The build already passes `-Iinclude`,
so either works.

Do not delete this directory. It is one of the submitted paths, and an absent
submitted path makes the archive step fail.
