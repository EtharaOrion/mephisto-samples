### Step 2: Feature construction

Weekly Friday-close frame with derived features:
- `DFF_chg_60d` = DFF[t] - DFF[t-9wk]
- `DGS2_chg_60d` = DGS2[t] - DGS2[t-9wk]
- `real_rate` = DFF[t] - CPIAUCSL_yoy[monthly_key(t)]
- `unrate_chg_1q` = UNRATE[m(t)] - UNRATE[m(t) - 3mo]
- `T10Y2Y` at Friday
- CPI YoY = (CPI[m] - CPI[m-12]) / CPI[m-12] * 100

### Step 3: FedRegimeClassifier (Stage 1, judge-side reference method)

5-state classifier via scipy K-means on standardized features with rule-based
prediction at inference:
- `|DFF_chg_60d| > 0.15` → hiking/cutting by sign
- `DFF_chg_60d > 0.05` OR `(DGS2_chg_60d > 0.20 AND real_rate > 1.0)` → on_hold_hawkish
- `DFF_chg_60d < -0.05` OR `(DGS2_chg_60d < -0.20 AND unrate_chg_1q > 0.10)` → on_hold_dovish
- else → on_hold_neutral

Rules derived from Fed policy operational lexicon. Class name
`FedRegimeClassifier` is JUDGE-SIDE ONLY per PKW-FAMILIES section 3
Framework B method-opacity rule; never appears in agent-visible surfaces.

### Step 4: PolicyPathProjection (Stage 2, judge-side reference method)

3-month-ahead DFF projection: `dff_delta_3mo ~ alpha + beta1 * (DGS2 - DFF) +
beta2 * (T10Y2Y_now - T10Y2Y_lag_1q)`. Fit on 2010-2024 weekly with
`DFF[t+13wk] - DFF[t]` target. Predicts forward Fed target path from market
short-end signal + term-premium compression.

### Step 5: MacroTransmissionModel (Stage 3, judge-side reference method)

2-stage per-regime OLS for 2Y and 10Y one-week-ahead yields:
- Stage A: per-regime `alpha + beta1*lag1_yield + beta2*DFF + beta3*cpi_yoy +
  beta4*unrate + beta5*T10Y2Y` where regime samples ≥ 30
- Stage B: persistence-with-drift fallback for thin regimes

Blended 45% model + 55% persistence at inference. Class name
`MacroTransmissionModel` is JUDGE-SIDE ONLY.

### Step 6: RegimeConditionalPositioner (Stage 4, judge-side reference method)

Composes duration + slope + carry positions conditional on regime label +
predicted yield deltas + policy-path projection:
- `duration_2y = -tanh(delta_2y / 15) * regime_scale`
- `duration_10y = -tanh(delta_10y / 25) * regime_scale * 1.2`
- `slope_2s10s = tanh((delta_10y - delta_2y) / 20) * regime_scale * 0.8`
- `carry_front_end = regime_carry_sign * min(1, |dff_proj|/0.5) * regime_scale`

regime_scale = {cutting: 0.7, on_hold_dovish: 0.4, on_hold_neutral: 0.3,
on_hold_hawkish: 0.5, hiking: 0.7}. Class name `RegimeConditionalPositioner`
is JUDGE-SIDE ONLY.
